このアプリについて

Daily Video YouTube Uploader は、所有者本人が自分のYouTubeチャンネルへ動画を投稿するための、個人用コマンドラインアプリです。一般向けの投稿サービスではありません。

投稿の流れ

アプリは完成動画をまず非公開でYouTubeへアップロードします。動画の処理状態と制作時の品質確認を確認し、著作権の申し立てはYouTube Studioで確認します。必要な確認がそろった後、同じ動画をYouTube Data APIで公開状態に変更し、公開状態を読み戻して確認します。

APIの処理完了は著作権チェックの代わりにはなりません。確認が不足している場合や、処理・権利上の問題を検出した場合は公開せず保留します。

データの送信先

動画ファイルと投稿用のタイトル・説明などは、投稿先であるYouTubeへ送信され、YouTubeの処理と保存を受けます。OAuth認証はGoogleを通じて行います。アプリは自分のチャンネル確認、動画のアップロード、状態確認、公開状態の変更に必要なYouTubeの権限を要求します。

運用記録には動画ID、ファイルのSHA-256、公開状態、確認時刻、確認証拠の場所などが含まれます。運用にCodexを使う場合、作業に必要なCLI結果や確認記録をCodexで扱うことがあります。認証秘密はこのPCのWindows DPAPIで暗号化して保存し、通常のCLI出力には表示しません。

この案内サイトは、動画、OAuth情報、フォーム入力を収集しません。アクセス解析や広告用の計測機能も設けていません。サイトの配信にはGitHub Pagesを使います。GitHubはページ配信に伴いIPアドレスなどの接続情報を処理する場合があります。詳しくはGitHubのプライバシーに関する声明を確認してください。

Googleデータの利用

Googleユーザーデータは、本人のYouTube投稿とその状態確認に必要な範囲で扱います。このアプリにGoogleユーザーデータを広告や生成AIの学習に使う機能はありません。Google API Services User Data PolicyのLimited Use要件に従います。

Googleアカウントの接続と権限はGoogleアカウントの接続済みアプリから確認・取り消しできます。取り消し後は、アプリからGoogle APIを利用できなくなります。

データの詳しい扱いはプライバシーポリシー、利用範囲は利用条件をご覧ください。
